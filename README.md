# Análisis de Ventas de Tienda de Teléfonos

## Descripción
Análisis de 10,000 registros reales de ventas usando Python y Pandas.

## Hallazgos principales
- Mejor vendedor: Laura Flores Guzmán con 673 unidades
- Producto más vendido: B018IZ0SWI con 5,267 unidades
